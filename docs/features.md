## 清单

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 评论系统 | 已完成 | 昵称 + 内容发表评论，存储于数据库并在文章页展示；暂未接入登录、通知与自动反垃圾 |

| 页脚 | 已完成 | 版权、建站时间、备案号、联系方式、RSS 与法务链接 |

## 上线前注意事项

- `frontend/src/config/site.js` 的 `url`：目前为 `https://example.com`，RSS、sitemap、canonical 都会使用该地址。
- `icp.label`：目前为占位文案，需替换为真实备案号。
- `author.email`、`author.github`：仍是示例值。
- 评论当前默认直接展示。发现不当内容时，可将 `comments.is_approved` 设为 `0` 隐藏，暂未提供管理后台。

## 后续建议

1. 评论系统后续可加入审核队列、频率限制、反垃圾与回复通知。
2. 首页目前是前端切片加载；接入后端文章接口后可改为服务端分页或无限滚动。
3. 搜索目前基于前端本地文章数据；接入后端 `/api/posts?q=` 后可支撑更大的文章量。
4. RSS 目前输出文章摘要；如需全文输出，可扩展 `frontend/scripts/generate-static.js`。
